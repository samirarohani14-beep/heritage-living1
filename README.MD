# Heritage Living

Heritage Living is a responsive website focused on showcasing traditional architecture, heritage properties, and architectural stories.

## About the Project

This project is developed as a graduation project to present and preserve the beauty of traditional architecture through a modern web interface.

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## Project Sections

- Header & Hero
- Categories
- Architectural Stories
- Properties
- Features
- Testimonials
- Footer

## Team

This project is developed collaboratively by our graduation project team.

## Responsive Design

The website is designed to work on desktop, tablet, and mobile screen sizes.
